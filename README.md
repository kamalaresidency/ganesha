# Kamala Residency — Shree Ganesha Festival Celebration

Official celebration website for **Kamala Residency** Ganesha Utsav celebration.

## Features
- **Live Fund Transparency Ledger**: Direct integration with community Microsoft Excel sheet on OneDrive.
- **276 Photo Memories**: Gallery and dynamic random glimpses from past celebrations.
- **Hero Video Showcase**: Devotional video darshan.
- **3-Day Celebration Schedule & Aarti Timings**: Daily morning & evening aarti timetable.
- **Interactive UI**: Marigold flower petal shower, synthesized temple bell chimes, mobile-responsive layout.

## Deployment to GitHub Pages
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and `/ (root)`.
4. Click **Save**. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
